# v0.1.7

Web-page update checks for games without GitHub repos:

- New optional metadata: `X-OGM-WebURL` / `X-OGM-UpdateURL` /
  `X-OGM-UpdateRegex` desktop keys (also `web_url` / `update_url` /
  `update_regex` on catalog and custom entries, and matching `ogm add`
  flags).
- `ogm refresh` polls the page (throttled like GitHub checks), extracts a
  version via regex or falls back to an ETag / Last-Modified / sha256
  fingerprint. First poll is a baseline; a later change raises an update
  badge; launching the game clears it.
- The card badge shows `↑ <version>` or `↑ site` with the source host in
  the tooltip.
- Page fetches use a browser-shaped User-Agent — fan-project hosts
  (rallysimfans et al.) 403 bot-like agents.
