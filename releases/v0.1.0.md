# v0.1.0

First release of omarchy-games-menu.

- Fullscreen QuickShell grid overlay (`games-menu`) with Steam-like cover art from
  SteamGridDB, sectioned into Games / Emulators / Tools
- Rust backend CLI (`ogm`): scans distrobox-gaming desktop entries, curated catalog
  of 69 entries with 36 GitHub-tracked repos, background release checks with update
  badges, SteamGridDB covers + release dates
- Sorting: Most played (frecency), Name, Date added, Release date, asc/desc;
  category chips + search; Ctrl+scroll cover zoom persisted as a preference;
  follows the Hyprland monitor scale
- Click to launch (auto-dismiss), right-click menu, add/remove/hide games via UI or CLI
- Integration API: `~/.config/ogm/catalog.d/*.toml` fragments (used by
  distrobox-gaming's `ogm_catalog` role)
