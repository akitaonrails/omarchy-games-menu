# v0.1.8

Thumbnail recovery and dependency maintenance:

- Repair orphaned SteamGridDB covers: when an artwork file exists but its
  `state.json` metadata link was lost, refresh now rebuilds the SGDB metadata
  instead of permanently skipping that cover.
- Add regression coverage for orphaned and missing cover files and preserve
  already-linked covers without unnecessary downloads.
- Upgrade `reqwest` to 0.13, `toml` to 1.1, and `sha2` to 0.11, alongside
  compatible lockfile updates.
- Preserve web-page SHA-256 fingerprints byte-for-byte across the `sha2`
  upgrade, with a known-answer compatibility test.
- Declare CMake explicitly for source-package builds required by the upgraded
  Rustls/AWS-LC dependency chain.
