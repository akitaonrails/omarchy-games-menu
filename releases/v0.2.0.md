# Omarchy Games Menu v0.2.0

## Highlights

- Follow the active Omarchy palette, launcher opacity, font size, and reduced-motion setting, including live updates while the overlay is open.
- Keep cover zoom independent from interface text size.
- Align spacing, corners, borders, focus treatment, and motion with the Omarchy SDK design language while retaining the QuickShell overlay architecture.
- Add keyboard focus and accessibility names, roles, and state to launcher controls and the Add Game dialog.

## Quality

- Add tested parsing and fallback behavior for Omarchy appearance data without changing `state.json`.
- Add QML convention tests, QML linting, a Rust 1.88 minimum-version check, dependency advisory checks, and unused-dependency checks to CI.
