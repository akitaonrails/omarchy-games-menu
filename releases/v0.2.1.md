# Omarchy Games Menu v0.2.1

## Highlights

- New **Launchers** section, rendered between Games and Emulators, for a single
  entry that fronts several games — an arcade series hub, a multi-title Proton
  launcher. Set `X-OGM-Category=launcher` on the desktop entry.
- A launcher declares what it covers with `X-OGM-Includes` (`;`-separated) or a
  catalog `includes` array. Search matches those titles, so "Daytona" finds the
  arcade hub that runs it, and the card's chip reads `launcher · 5 titles`.
- New `emulated` category for a single game that runs through an emulator or an
  emulator-derived runtime. It renders in **Games**, alongside `arcade`.

## Why `emulated` exists

`emulator` means the emulator *application* — RPCS3, Dolphin, RetroArch — and it
gets its own section. Entries that tagged a *game* that way because an emulator
powers it ended up filed next to Dolphin: a GT6-tuned RPCS3 build, a
Dolphin-derived single-game runtime, a game launched in an emulator. `emulated`
is the category those belong in, and the README now documents what each category
means so the next entry is not a judgment call.

## Compatibility

`includes` is omitted from `state.json` when empty, so entries that predate it
keep their exact shape; a serialization test locks that. An older `ogm` treats an
unknown `X-OGM-Category` as absent and falls back to the bundled catalog or
`custom`, so desktop files can adopt the new values before every machine is
updated.
