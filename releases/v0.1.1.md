# v0.1.1

- The AUR package now installs a "Games Menu" .desktop launcher
  (/usr/share/applications/omarchy-games-menu.desktop)
- ogm now consumes launcher metadata embedded in .desktop files via X-OGM-*
  keys (X-OGM-Managed marker, X-OGM-Category, X-OGM-GitHub, X-OGM-SGDBQuery).
  Marker metadata takes precedence over catalog fragments and the bundled
  catalog; legacy filename-glob discovery remains as fallback until
  distrobox-gaming migrates its rendered entries.
