# v0.1.4

- Releases now ship a prebuilt `x86_64` binary tarball (built on GitHub
  Actions) alongside the source.
- New AUR package `omarchy-games-menu-bin` installs that prebuilt binary —
  no local Rust toolchain needed. It provides/conflicts with the source-based
  `omarchy-games-menu` package, which continues to be published as before.
