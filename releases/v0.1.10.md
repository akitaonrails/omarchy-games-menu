# v0.1.10

Controller support, so the menu is usable from the couch:

- `ogm gamepad` is a new subcommand that streams controller input as
  line-delimited JSON; the overlay starts it on open and it dies with the
  overlay. Pads are found by capability in `/proc/bus/input/devices` rather
  than by udev symlink, so USB, Bluetooth and virtual pads all work and a
  keyboard that happens to expose a joystick node is not mistaken for one.
  Discovery reruns every two seconds, so a wireless pad that connects (or
  wakes) after the menu is already open still works. `ogm gamepad --list`
  shows what it found, and whether the device is readable.
- Bindings: left stick and D-pad move the selection, **A**/**Start** launch,
  **B** closes the menu, **LB**/**RB** step through category filters,
  **X** flips the sort direction, **Y** steps through the sort keys,
  **LT**/**RT** step through the S/M/L cover sizes, and **Select** triggers a
  rescan and fetches any artwork that is still missing.
- Arrow keys now move a selection cursor too, with **Enter** to launch.
  Holding a direction accelerates: 400ms before the first repeat, so a tap
  moves exactly one card, then ramping from ~220ms down to ~45ms over about a
  second. The stick, the D-pad and the arrow keys all feed the same ramp.
  The selected card gets a highlight ring and the grid scrolls just enough to
  keep it in view.

Also:

- The grid now uses the full width at every cover size. Cells stretch so the
  columns tile the available width exactly and the leftover is spread into
  the gutters, instead of collecting as dead space along the right edge.
