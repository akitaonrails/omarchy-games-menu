# v0.1.5

Overlay input overhaul:

- The overlay now grabs keyboard focus (wlr-layer-shell Exclusive). This
  fixes Ctrl+wheel zoom silently degrading to plain scrolling, enables
  key navigation, and lets the compositor's close-window bind (e.g.
  Super+W) close the launcher.
- Type anywhere to filter instantly — no need to click the search field;
  Backspace edits the query.
- Page Up / Page Down scroll a page; Home / End jump to top/bottom.
- F5 or Ctrl+R rescans installed games (`ogm scan`).
- Ctrl+Q quits; Super+W now also terminates the process cleanly.
- New S/M/L cover-size preset buttons in the top bar (0.7x / 1.0x / 1.5x).
- Ctrl+wheel zoom now tolerates extra modifier bits (e.g. NumLock)
  instead of requiring an exact match.
