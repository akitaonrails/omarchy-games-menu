# v0.1.2

- SteamGridDB search now walks autocomplete candidates (exact-name match first)
  and picks the first entry that actually has 600x900 grid art, instead of
  recording a gridless first hit forever. Games whose lookup previously found
  no grid are retried on the next refresh.
- Catalog fixes: Starship cover now resolves via "Star Fox 64"; Wipeout PE via
  the 1995 original "Wipeout".
